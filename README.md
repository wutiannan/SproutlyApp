# 灵想（Sproutly）

灵想是一款面向 ASD 儿童艺术疗愈场景的 iOS 交互原型。项目使用 SwiftUI 构建界面，并通过 ARKit、RealityKit、Speech 与 AVFoundation 提供真实 AR、语音识别和声音反馈能力。

## 当前功能

### 首次启动

- 9 个连续引导状态，包含开屏动画、协议确认、登录输入和昵称输入。
- 首次完成后记录引导状态；App 从后台重新进入时会再次播放开屏动画。

### 首页

- 左上角四种情绪球选择，选择后同步更新首页情绪球状态。
- 右上角功能入口展开与收起。
- 点击 KAKA 打开底部装扮弹窗，可横向浏览并选择装扮或心情形象。
- KAKA 形象保存在本机，并同步显示在首页、音乐、AR 和社区页面。

### 音乐

- 愉悦、平静、期待、低落四种情绪卡片，可循环横向切换。
- 情绪球和音波根据当前情绪持续播放动态效果。
- 卡片详情支持继续切换情绪、进入曲库或生成对应的情绪调节路径。
- 每种情绪包含三段渐进引导：低落会从陪伴逐步过渡到温暖明亮，兴奋与期待会从同频逐步过渡到舒缓专注。
- 四种情绪分别匹配一首经过筛选的在线授权音乐作为稳定底层，并叠加由 iPhone 本地实时生成的柔和音符。
- 情绪决定实时音符的调式、基础音高和音乐速度；填入的颜色决定音高与音色明亮度，封闭区域大小决定音符长度和音区。
- 低落情绪会随引导进度从小调色彩逐步转向明亮和声，期待与愉悦会逐渐降低播放速度，帮助兴奋状态平稳下来。
- 每次成功填充封闭区域都会触发对应音符和一次同步音波脉冲；快速连续填色使用三个合成声部，避免声音延迟堆积。
- 音乐支持暂停与继续。工程中只保存在线播放地址和实时合成代码，不包含 MP3、M4A、WAV 等音频文件。
- 填色页面包含三张线稿，每个封闭区域可独立着色，后续填色不会影响其他区域。
- 音乐引导与正念填色同步进行，麦克风音量可驱动唱歌音波；结束后会询问调节后的主观感受。

当前版本使用可解释的本地情绪映射完成调节方案、曲目匹配与实时合成参数控制，情绪、填色和录音数据不会上传。代码已将匹配逻辑独立为 Provider，后续获得合规的大模型服务、儿童隐私方案和正式曲库后，可以替换为在线情感计算与正式音乐服务。

- 当前链接适合原型演示；正式上架前建议将已确认授权的曲目部署到自有 CDN，避免第三方链接变更影响播放。

#### 大模型接口方案

- 推荐使用 OpenAI Responses API 与 `gpt-5.6`，通过 Structured Outputs 固定返回三阶段调节计划。
- 模型只接收当前情绪、粗粒度的填色进度和调节后反馈；不上传儿童姓名、原始录音或语音内容。
- 返回字段限定为目标情绪、阶段名称、音乐标签、节奏范围、唤醒度和愉悦度，再由 App 在白名单音乐库或本地合成器中匹配声音。
- API Key 必须保存在自有后端的环境变量中，iOS App 只调用自有后端，不能把 Key 写入工程或安装包。
- 面向 13 岁以下儿童处理个人数据前，需要先为 API 项目开通 Zero Data Retention，并完成监护人同意和适龄内容保护。
- 网络不可用、接口超时或返回内容校验失败时，自动回退到当前本地情绪映射，保证核心调节流程可继续使用。

### AR 世界

- 两个连续任务均通过按住话筒说话作答，并实时显示语音转写结果。
- 支持正确与错误反馈、桃花和荷花奖励、拖动植物并放置到真实空间。
- 完成任务后可进入植物互动、声音互动和植物收集页面，并返回 AR 世界首页。

### 社区

- 双列社区世界卡片支持纵向滚动。
- KAKA 使用全局已选择的形象。
- 支持从指定卡片进入世界详情及后续演示页面。

### 我的

- 植物记录卡片支持纵向滚动查看。
- 首页选择心情、音乐情绪选择与音乐引导后的反馈都会生成真实情绪记录。
- 情绪记录仅保存在当前设备，最多保留最近 730 条，不依赖账号、网络或云端服务。
- 情绪记录页会按最近 7 天的真实数据，动态生成主要情绪占比、情绪波动曲线和分组统计图；无记录时显示空状态，不使用演示数据填充。
- 动态图表沿用设计稿的卡片尺寸、位置、颜色和自定义字体，家长管理仍为独立页面。
- 退出入口会清除首次启动标记，重新进入引导流程。

## 技术与环境

- SwiftUI
- ARKit 与 RealityKit
- Speech
- AVFoundation
- 最低系统版本：iOS 17
- 目标设备：iPhone，竖屏
- App 显示名：灵想
- 工程、Target 与 Scheme：Sproutly
- Bundle ID：`com.example.Sproutly`

AR、相机、语音识别和麦克风交互需要在支持 ARKit 的真机上测试。模拟器适合检查普通页面和基础交互，但不能完整验证真实 AR 放置效果。

## 运行

1. 使用 Xcode 16 或更新版本打开 `Sproutly.xcodeproj`。
2. 选择 `Sproutly` Scheme。
3. 在 **Signing & Capabilities** 中选择开发团队；如 Bundle ID 已被占用，请改为自己的唯一标识。
4. 普通界面可选择 iPhone 模拟器运行；AR 与语音流程请选择已开启开发者模式的 iPhone。
5. 首次进入 AR 或音乐录音功能时，允许相机、麦克风和语音识别权限。
6. 音乐引导采用在线播放，测试时需要保持网络连接。

若要重新查看首次启动引导，可在“我的”中使用退出入口，或卸载 App 后重新安装。

## Xcode Canvas 预览

打开 `Sproutly/PreviewCatalog.swift`，通过 **Editor → Canvas**（`Option + Command + Return`）显示预览区。当前提供 7 个预览：

1. 首次启动引导
2. 首页
3. 音乐
4. AR 世界1
5. 社区
6. 我的
7. 完整 App

Canvas 中的相机、麦克风和语音识别能力受预览环境限制，完整流程以真机结果为准。

## 主要目录

- `Sproutly/RootView.swift`：首次启动、开屏动画和底部导航。
- `Sproutly/GardenHomeView.swift`：首页及 KAKA 装扮交互。
- `Sproutly/FigmaBaseScreens.swift`：音乐、社区、我的及通用 Figma 画布组件。
- `Sproutly/LiveARView.swift`：AR 任务、语音转写、植物动画与空间放置。
- `Sproutly/Models.swift`：全局页面状态、KAKA 形象状态，以及设备本地的真实情绪记录。
- `Sproutly/PreviewCatalog.swift`：Xcode Canvas 单页预览。
- `Sproutly/Assets.xcassets`：设计稿导出资源和动画素材。
